# 结果解释

本文说明现有 `dispatch.csv` 和 `summary.json` 的字段。程序将一天表示为
144 个十分钟时段。负荷、光伏、购电、充电、放电和弃光等流量是**每个时段的
kWh**，不是 kW。SOC 是时段边界的储能状态，单位为 kWh，不是时段流量。
`price_per_kwh` 使用输入数据中的货币单位/kWh，成本也使用相同货币单位。

## `dispatch.csv`

| 字段 | 含义及物理意义 | 单位 | 数值理解 |
| --- | --- | --- | --- |
| `start_minute` | 时段相对于午夜的开始时间 | 分钟 | 第一个时段从 0 开始。 |
| `end_minute` | 时段相对于午夜的结束时间 | 分钟 | 每个时段为十分钟。 |
| `load_kwh` | 该时段负荷消耗的电量 | kWh/时段 | 输入的时段需求。 |
| `pv_kwh` | 该时段光伏发出的电量 | kWh/时段 | 弃光前的输入光伏电量。 |
| `price_per_kwh` | 电网购电价格 | 输入货币单位/kWh | 用于计算购电成本的输入价格。 |
| `purchase_kwh` | 优化调度中该时段从电网购买的电量 | kWh/时段 | 用于平衡该时段的电网电量。 |
| `charge_kwh` | 该时段送入电池充电的电量 | kWh/时段 | 充电损耗会减少 SOC 的增加量。 |
| `discharge_kwh` | 该时段由电池放电提供的电量 | kWh/时段 | 因放电损耗，SOC 减少量大于交付电量。 |
| `curtailed_pv_kwh` | 模型未利用的光伏电量 | kWh/时段 | 为零表示可用光伏均用于负荷和/或充电。 |
| `soc_start_kwh` | 时段开始时电池的荷电状态 | kWh | 等于上一行的 `soc_end_kwh`。 |
| `soc_end_kwh` | 时段结束时电池的荷电状态 | kWh | 反映充放电效率后的变化。 |
| `baseline_purchase_kwh` | 同一输入时段停用电池调度时的电网购电量 | kWh/时段 | 对比基线，不是第二个优化调度。 |

若要将某个流量换算为该时段的平均功率，可将 kWh 除以时段小时数（10/60）。
这只是单位换算，不代表实测功率曲线。

## `summary.json`

| 字段 | 含义 | 解释 |
| --- | --- | --- |
| `optimized_cost` | 优化购电的模拟总成本 | 各时段购电电量乘以对应电价后求和。 |
| `battery_disabled_baseline_cost` | 停用电池的模拟基线总成本 | 使用相同的负荷、光伏和电价，不进行电池调度。 |
| `simulated_cost_difference` | 基线成本减去优化成本 | 正值表示在这些假设下优化购电的模拟成本更低；负值表示更高。 |
| `simulated_cost_reduction_percent` | `100 × (基线成本 - 优化成本) / 基线成本` | 基线成本为零时为 `null`；否则是模拟百分比，不是财务收益。 |
| `optimized_purchases_kwh` | 优化调度的购电量总和 | 全天模拟电网购电量。 |
| `baseline_purchases_kwh` | 基线购电量总和 | 停用电池时全天模拟电网购电量。 |
| `solver_mip_gap` | 求解器报告的混合整数最优性间隙 | 无量纲求解器量；未提供时可能为 `null`。 |
| `solver_message` | 求解器终止信息 | SciPy/HiGHS 返回的诊断文本。 |
| `constraints` | 对输出调度进行的代数检查 | 见下方“约束诊断”。 |
| `disclaimer` | 程序写入的范围说明 | 结果不是电网控制软件，也不声称存在真实收益。 |

模拟成本差额按以下方式计算：

```text
模拟成本差额 = 停用电池基线成本 - 优化成本
```

### 按时段计算购电成本

当前 CSV 没有独立的时段成本字段。可用已有字段计算：

```text
时段购电成本 = purchase_kwh × price_per_kwh
全天购电成本 = 所有时段购电成本之和
```

例如，某时段 `purchase_kwh = 12`，`price_per_kwh = 0.40` 货币单位/kWh，
则该时段模拟购电成本为 `12 × 0.40 = 4.80` 货币单位。将 144 个时段成本
相加即可复算优化购电成本，结果可能有正常的浮点舍入差异。

## SOC 轨迹与效率

`soc_start_kwh` 和 `soc_end_kwh` 分别表示时段开始、结束时储存的能量。模型的
时段关系为：

```text
SOC 终值 = SOC 初值
          + 充电效率 × charge_kwh
          - discharge_kwh / 放电效率
```

充电效率小于 1 时，储存的能量小于充电输入；放电效率小于 1 时，消耗的储能
大于输出电量。初始 SOC 和终止 SOC 是模型约束。CLI 的停用电池基线要求两者
相等。

## 光伏利用

`pv_kwh` 是输入的光伏发电量，`curtailed_pv_kwh` 是模型未利用的部分。每个
时段的光伏总利用量可计算为：

```text
光伏利用量 = pv_kwh - curtailed_pv_kwh
```

当前输出无法说明光伏中有多少直接供负荷、多少用于电池充电，也无法标识每一
单位充电电量的来源。不要根据这些文件推断上述分配比例。

## 约束诊断

`constraints` 对象包含：

| 字段 | 含义 | 单位/理解 |
| --- | --- | --- |
| `max_balance_residual_kwh` | 最大绝对时段能量平衡残差 | kWh；在数值容差范围内应接近零。 |
| `max_soc_residual_kwh` | 最大绝对 SOC 递推残差 | kWh；在数值容差范围内应接近零。 |
| `max_constraint_violation` | 多项校验中的最大数值，包括流量负值、弃光及充放电上限、SOC 上下限与初末值偏差、总成本一致性，以及同时充放电时段数 | 混合诊断汇总量，没有单一物理单位；不能将其视为仅以 kWh 计量的残差。 |
| `simultaneous_charge_discharge_slots` | 充电和放电同时超过校验阈值的时段数 | 时段；预期为零。 |
| `min_soc_kwh` | SOC 轨迹中的最低值 | kWh。 |
| `max_soc_kwh` | SOC 轨迹中的最高值 | kWh。 |

`max_balance_residual_kwh` 和 `max_soc_residual_kwh` 分别报告，不计入
`max_constraint_violation`。后者还包括初始及终止 SOC 偏差、报告总成本与重新
计算成本之间的差值，以及同时充放电时段数。由于它混合了以能量表示的检查量、
成本差值和时段计数，因此没有单一单位。应将其理解为综合校验诊断值，而不是
以 kWh 表示的物理残差。

## 结果局限

这些结果是根据输入数据和模型假设进行的数学优化模拟，不代表真实电网运行
结果，也不代表实体电池的实际性能。模拟成本差额不是已实现的财务节省。不得
将软件用于真实电网、保护系统或电池控制器。
